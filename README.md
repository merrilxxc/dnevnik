# 📔 Дневник дней

Простой личный дневник в браузере: оценка дня от 1 до 10, настроение, смайлик, пара строк и фото.
Со временем показывает календарь, тепловую карту года, «что было в этот день год назад» и подсказки, что делает дни лучше.

**Все записи хранятся только в браузере на твоём устройстве.** Нет аккаунтов и сервера, ничего никуда не отправляется.
Чтобы не потерять записи, раз в пару недель жми «💾 Сохранить копию».

Подсказки — статистика по записям, а не диагноз. Если тяжело: Lifeline Ukraine — 7333 (бесплатно, круглосуточно), при угрозе жизни — 112.
